Opsætning af Express og Pug:
1. Gå til terminalen og find stien, hvor du ønsker at gøre Express og Pug brugbar.
2. Kør: "npm init -y", "npm install express pug" og "npm pkg set type=module"
3. Filerne "node_modules", "package-lock.json" og "package.json" er nu oprettet og klar til brug.
